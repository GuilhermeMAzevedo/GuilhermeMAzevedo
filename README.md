- 🎓 Graduando em Ciência da Computação — UNIFOR
- 👨‍🏫 **Monitor voluntário** de *Resolução de Problemas de Natureza Discreta*
- 🔭 Atualmente trabalhando em uma **aplicação web de agendamento de laboratório** para o NUBEX (UNIFOR)
- 🤖 Explorando **sistemas embarcados** com ESP32
- 🌱 Aprendendo HTML, CSS e JavaScript
- 💼 **Aberto a oportunidades de estágio** em desenvolvimento de software
